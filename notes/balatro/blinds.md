# ブラインド・ボス・タグ

## 目標点（このランで見た値）

この表は観察。ヒエログリフで 1 回アンティを戻したので、アンティ 1・2 は 2 回見た。

| アンティ | スモール | ビッグ | ボス |
|---|---|---|---|
| 1 | 300 | 450 | 600 |
| 2 | 800 | 1,200 | 1,600 |
| 3 | 2,000 | 3,000 | 4,000 |
| 4 | 5,000 | 7,500 | 10,000 |
| 5 | 11,000 | 16,500 | 22,000 |
| 6 | 20,000 | 30,000 | 40,000 |
| 7 | 35,000 | 52,500 | 70,000 |
| 8 | 50,000 | 75,000 | 100,000 |

- ビッグはスモールの 1.5 倍、ボスは 2 倍（観察）

## ボス

効果は、ブラインド選択画面の説明文（確実）。

| ボス | 効果 | 戦い方・観察 |
|---|---|---|
| 柱 | このアンティの間にプレイされたカードにデバフ | 該当カードに赤い×印が付く（観察） |
| 手枷 | ハンドサイズ -1 | 手札 7 枚 |
| ゴアド | すべてのスペードにデバフ | スペードを寄せた直後に来ると痛い |
| 目 | このラウンドでは同じ役を 2 回出せない | 最初の 1 ハンドで決める |
| 家 | 最初のハンドは裏向きでドローされる | 最初の 8 枚が全部裏向き。裏向きはカーソルでも読めない。ディスカードで引いた札は表向き（観察） |
| 魚 | 各ハンドをプレイ後に裏向きでドローされる | ディスカードで引いた札は表向き。1 ハンドで決めるのが安全（観察） |
| フリント | ベースチップと倍率が半分 | ジョーカーの倍率は減らず、フルハウス 1 ハンドで 4 万を超えた（観察） |
| 歯 | カードがプレイされるたびに $1 失う | 5 枚の役 1 回なら $5。所持金はマイナスになる（$3 から $-2 になった。観察） |
| フック | ハンドをプレイするたびに、手札からランダムに 2 枚捨てられる | ディスカードで役を作り、1 ハンドで決める（観察） |
| 頭 | すべてのハートカードにデバフがかかる | ブラインド選択画面で読んだ（未対戦） |
| セルリアンベル | 常に 1 枚が強制的に選択される | その 1 枚を入れて役を作る（アンティ 8） |

- デバフのカードは、役の形には入るがチップは出ない（推測）

## タグ（スキップの報酬）

効果は、カーソルで読んだ画面の説明文（確実）。

| タグ | 効果 |
|---|---|
| 投資タグ | ボスを倒すと $25（観察: 実際に $25 増えた） |
| エコノミータグ | 資金を 2 倍（最高 $40）。スキップしてすぐ増えた（観察） |
| ガーベジタグ | このランで使わなかったディスカード 1 回につき $1（最高 $46） |
| D6 タグ | 次のショップのリロールが $0 から |
| アンコモンタグ | ショップに無料のアンコモンジョーカー |
| バウチャータグ | 次のショップにバウチャーを 1 枚追加 |
| レアタグ | ショップに無料のレアジョーカー |
| ホログラムタグ | 次のショップジョーカーが無料・ホログラム（倍率 +10） |
| トップアップタグ | コモンジョーカーを最大 2 枚（空きが必要） |
| オービタルタグ | ある役を 3 レベル上げる（役は出るたびに違う） |
| チャームタグ | 無料のメガアルカナパック |
| スタンダードタグ | 無料のメガスタンダードパック。スキップ直後にパックが開いた（観察） |
| ジャグルタグ | 次のラウンドでハンドサイズ +3 |
| ボスタグ | ボスをリロール |
| ダブルタグ | 次に選んだタグのコピー |

- まだ選べないブラインド（ビッグ）のタグは、カーソルを 2 秒置くと説明が出る（観察）
