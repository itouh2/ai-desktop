## 無色カード

- どのキャラにも出るカード。クエーサー+、権威の体現+、無色ポーションなどで手札に入る。
- ★のキャラのランで読んだ、ゲーム内の説明文（確実）。

| カード | コスト | 種類 | 効果 |
|---|---|---|---|
| 一閃（無色） | 0 | アタック | 5 ダメージ。1 枚引く |
| ジャックポット（無色） | 3 | アタック | 25 ダメージ。ランダムなコスト 0 のカードを 3 枚手札に加える |
| 苛立ち（無色） | 0 | スキル | 保留。手札が 0 枚の場合、2 枚引き、エネルギーを 2 得る |

| 究極のストライク（無色） | 1 | アタック | 14 ダメージ |
| 四方斬り（無色） | 0 | アタック | 8 ダメージ。与えたダメージと同じダメージを、他のすべての敵に与える |
| 背水の陣（無色） | 0 | スキル | 50 ブロック。この戦闘中、ブロックできずに攻撃ダメージを受けたら即死 |
| 祓い清め（無色） | 0 | スキル | 保留。手札のカードを 3 枚まで廃棄。廃棄 |
| 焦燥（無色） | 0 | スキル | 手札にアタックがない場合、2 枚引く |
| 非常ボタン（無色） | 0 | スキル | 30 ブロック。2 ターンの間、カードからブロックを得ることができない。廃棄 |
