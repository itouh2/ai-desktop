## 画面の見方

座標は、撮影画像（1568×917）のピクセルの目安。

| 場所 | 位置 |
|---|---|
| カード報酬（3 枚） | 左 x≈400–600、中央 x≈685–885、右 x≈965–1165、y≈395–670 |
| カード報酬の「スキップ」 | (785, 780) 付近 |
| 「ターン終了」ボタン | (1390, 755) 付近 |
| 手札 | 画面下部 y≈730–915 に扇状に並ぶ。**左端と右端が切れる**ので、読めないカードがあると言う |
| 敵 | 画面右側（x≈900–1500、y≈300–650） |
| エネルギー | 左下。★を使うキャラは、その下に青い星と数字で★が出る |
| 商人 | カードが上の 2 段、レリックとポーションが右下、カード削除は右下の金貨 |
| マップ | 上側が見切れる。先の分岐は、スクロールして見せてもらう |

- 説明文（状態アイコン、敵の意図、レリック、見切れた手札）は、画面の中に描かれる。`capture_window` の画像の座標で `move_mouse` すれば読める。
- 説明文が出るまで時間がかかることがある。羽ばたきの説明文は、`move_mouse` の `wait_seconds` を 1.5〜2 にすると読めた。
- カード左上の数字がコスト。オレンジがエネルギー、青い星が★（★を使うキャラ）。
- 敵や自分の足元に、状態のアイコンが並ぶ。分かっているものは [enemies.md](enemies.md)「足元のアイコン」。

敵の意図の表示（説明文で読んだ。紫のカードだけ推測）:

| 表示 | 意味 |
|---|---|
| 攻撃的（剣と数字） | アタック |
| 守備的（盾） | ブロックを得る |
| 強化（上向き矢印） | バフを使う |
| 紫のカード | 状態異常を入れてくるもの（**推測**） |

- 敵の攻撃予告は、筋力の変化（星の終わりなど）をすぐ反映する（観察）。筋力を下げたら、予告の数字を見てから、残りのブロック量を決める。
- **予告は毎ターン、撮った画像の数字で読む。行動の周期から決めつけない。** 知識の悪魔は 4 ターンごとにデバフだったが、13 ターン目は単発 23 だった。「デバフのはず」と読んで守りを 5 しか張らず、HP 21 → 3 になった（アイアンクラッドのラン）。
- 背後からの攻撃の上乗せも、予告の数字に入る（観察。[enemies.md](enemies.md) のクラッシャー＋ロケット）。

## ルールと注意

キャラを問わない決まりと、間違えやすいこと。

- **手札は基本、次のターンに持ち越せない。** 「温存」の助言は無効。そのターンに使い切る前提で組む。
  - 例: 「劇的な入場を、敵が 2 体のときまでとっておく」はできない。天賦は戦闘開始時に手札に入る効果で、とっておく効果ではない。
  - 例外は保留のカード（「用語」）。
- **パワー（ブラックホールなど）は戦闘ごとに使い直す。** 次の戦闘には残らない（プレイヤーの指摘）。
- **愚行（呪い）は、商人のカード削除でも削除できない**（プレイヤーの教え）。削除の候補にしない。
- **ツタが付いたカードは、1 ターンに 1 枚しか使えない**（プレイヤーの教え）。手札に複数あっても、1 枚だけ。
  - ボスの効果と推測。
  - ツタ付きの手札を、守りと攻撃の両方に取らない。
- 復活する敵がいる（第 3 幕のロボ。第 2 幕・フロア 29 のパラライトも、倒した次のターンに HP 満タンで復活した）。倒したあとの画面が「HP 満タン」なら、復活の可能性を疑い、撮り直す（例: [enemies.md](enemies.md) のロボとパラライト）。
- イベント「人型の穴」など、**効果が分からない選択は、先に調べる**（Firecrawl の `firecrawl_search`。使えなければ WebSearch）。Firecrawl の MCP はユーザー側に登録済み。
- 脆弱が大きいと被ダメージが増える（推測）。受けるダメージを数えるときは、脆弱の倍率と、攻撃回数の増加（12×3 → 16×3）を織り込む。
- ボス前の HP は **50 以上**を目安にする。敵の攻撃が連続で上がるボス戦は、HP が 50 以上ないと勝てない。
  - HP が低いときは、休憩所、洋ナシのレリックなどで最大 HP を伸ばす。
- 休憩所を取りこぼさない。第 3 幕では、マップを見て、ボスの手前の休憩所を必ず通る（マップの見方は「画面の見方」）。
- 解析やソウルなど、**引くカードを先に使う**。引いた手札を撮り直して見てから、残りの手順を出し直す。
- 第 3 幕に入ると、HP が全快した（3 → 75。★のキャラのラン）。
- **第 2 層も、マップ下の野営地（スタート地点の絵）を押すと、古の存在のイベントが始まり HP が全快した**（9 → 84。アイアンクラッドのラン、2026-10-06）。層が変わった直後は、敵のマスを押しても進まない。先に野営地を押す（観察）。
  - 第 2 層の古の存在「ダーヴ（収集家）」の選択肢: エクトプラズム（ゴールドを獲得できなくなる。ターン開始時エネルギー +1）／パンドラの箱（ストライクと防御をすべて変化）／空っぽの檻（カードを 2 枚削除）（確実: 画面の説明）。エクトプラズムを選んだ。

## 用語

画面に出る言葉と、その意味。キャラ固有の言葉（破滅、オスティ、★、鍛造など）は、`characters/` のキャラのファイルにある。

- 幕: マップの区切り（第 1〜3 幕）（推測）。盗賊系のランの記録では「層」と書いた（フロア 48 の砂時計は、どちらの書き方でも 3 つ目の最後）（推測）。
- 保留: ターン終了時に捨て札にならない（次のターンに持ち越せる）（確実）。ネクロバインダーではパチンなど。
- エセリアル: 使わないと消える。ターン終了時に手札にあると廃棄される（確実: 不器用の説明文）。
- 廃棄: 戦闘終了時まで取り除かれる（確実）。
- 天賦: 戦闘開始時に手札に入る効果。とっておく効果ではない。
- 永劫: 削除・変化できない（確実: 心酔の説明文）。
- 脱力: アタックで与えるダメージが 25% 減る（確実）。
- 弱体（アイコンは割れたハート）: アタックから受けるダメージが 50% 増える（確実）。
- 脆弱（足元の割れたハート）: 数字が大きいと、受けるダメージが増える（推測: 1.5 倍）。読めたら、ブロック量を多めに見積もる。
  - 割れたハートを、ネクロバインダーのランでは脆弱、★のキャラのランでは説明文どおり弱体と書いた。どちらが正しいかは「未確認」。
- アーティファクト: デバフを無効化する。数字の回数だけ（砂時計の「アーティファクト 2」）（推測）。
- 魂力（エンチャント）: 廃棄を失う（確実）。

- 割れたハートのアイコンの名前（脆弱か弱体か）と、脆弱の効果。★のキャラのランでは、脆弱は弱体と別のデバフとして出た（アックスマシンが脱力・脆弱を付けてきた）。

- カードの正式な効果テキスト。報酬画面で読んだ分だけ、日本語名と効果をまとめる。ネクロバインダーと★のキャラは `characters/` にある。盗賊系はまだない。
