# 開始までの流れ

チュートリアル付きの新規開始で、ゲームが始まるまでの画面。座標は撮影画像（1568×1019）の目安（観察）。ゲーム全体のことは [README.md](README.md)。

右上に茶色い吹き出し（チュートリアル）が出て、その画面でやることを教えてくれる（確実）。

## 1. 惑星を創造

- 吹き出しに「今はデフォルトの設定が良いでしょう。先に進めたら"創造する"をクリックしてください」とある（確実）。
- デフォルトは、生成範囲 30%、平均降水量・平均気温・人口がすべて「普通」（確実）。
- 「創造する」は右下 (1263, 921)（観察）。押すと「世界を生成しています」の読み込みになる。

## 2. 開始位置を選択

- 吹き出しに「茶色い丘のない、温帯森林の平地（薄緑色の場所）を選びクリックし、"次へ"をクリックします」「"地形タブ"を使えば、選択したタイルの詳しい情報が見れます」とある（確実）。
- マスをクリックすると、左に情報パネルが出る（バイオーム、地形、年平均気温、成長期間、降雨量、疾病の頻度 など）。下に、そのマスの名前（村なら村名と派閥）が出る（確実）。
- 地図の地名ラベル（「〜林」「〜雨林」「〜砂漠」「〜針葉樹林」「〜大草原」）が、バイオームの手がかりになる（観察: 「〜林」の辺りのマスが温帯森林だった）。
- 他勢力の拠点のアイコン（家、テント、ドクロ など）が乗ったマスは、その勢力の村。クリックすると「穴村、派閥: アズオァエン、中立 (0)」のように出る（確実）。そこには入植できない（推測: 一般的な知識。試していない）。
- 「次」はマスを選ぶ前は (1060, 970)、選んだあとは左のパネルの分ずれて (1162, 970)（観察）。

注意:

- 候補の範囲を枠で示すときは、勢力のアイコンが乗っていない場所を囲む。アイコン入りの範囲を示したら、ユーザーが村のマスを選んだ（観察）。
- 地図の地形の色は、拡大したり時間がたったりすると黒く描かれて見えなくなることがある（観察）。そのときは地名ラベルと、クリックした情報パネルで判断する。

## 3. キャラクターの作成

- 上の「選択済」の 3 人で始まる。下の「置き去り」は連れて行かない人（確実）。
- 人物をクリックすると、右に詳細（年齢、幼年期・成年期、技能と炎マーク、才能・性格、苦手・欠点、健康、相関関係、所有物）が出る（確実）。下の「チームスキル」は選択済の 3 人の最大値（推測: 入れ替えると数字が変わった）。
- 一覧にカーソルを乗せても「ドラッグで順序の変更」としか出ない。能力は人物をクリックしないと読めない（確実）。
- 並び替えはドラッグ（確実: 吹き出し「"置き去り"にいるキャラクターを"選択済"にドラッグしてみてください」）。選択済の人を置き去りへドラッグすると、置き去りの先頭の人が選択済に上がる（観察）。
- 右上の「ランダム化」で、表示中の人物を別人に引き直せる（観察）。吹き出しの裏に半分隠れていて、見えるのは「ラ」の字だけ（観察: (1135, 205) 付近）。
- 性格は、カーソルを乗せると説明文が出る（確実）。読んだものは [traits.md](traits.md)。
- 「スタート」は右下 (1263, 921)（観察）。押すと「地図を作成しています」の読み込みになる。
- 吹き出しに「完璧なキャラクターを求めようとしないでください。誰しも欠点を持っています」とある（確実）。

選び方の目安（推測: 一般的な知識。この回の判断の元）:

- 序盤に要るのは、建築・栽培・料理・射撃・医術・知力（研究）。
- 「苦手・欠点」に「運搬」「雑用」「消火」「高度な作業」などがある人は、少人数では使いにくい。
- 「放火魔」なのに「消火」ができない、のような組み合わせは避ける。
- 元恋人などで仲が悪い 2 人（相関関係が大きなマイナス）は、同時に入れない。

## 4. ゲーム開始

- 「冬眠カプセルで眠っていたあなた達 3 人は…」の物語が出る。[OK] で閉じる（確実）。始まった時点では一時停止中（確実: 速度の「Ⅱ」が明るかった）。
- この先は [tutorial.md](tutorial.md)。
