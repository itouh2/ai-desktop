## 概要

- 不時着した入植者を指示して、拠点を作って生き延びるゲーム。入植者は自分で動き、プレイヤーは「どこに何を作るか」「誰に何をさせるか」を指示する。
- 日本語表示。DLC なし（Core のみ）、Mod なし（確実: 読み込み画面の「公式コンテンツ」「Mods なし」）。
- ウィンドウタイトル「RimWorld by Ludeon Studios」。撮影は `capture_window(title="RimWorld by")`。これで 1 つに絞れた（観察）。`title="rimworld"` だと、注釈ページのブラウザのタブ（タイトルが「ai-desktop | RimWorld 案内: …」）とも一致して、候補が 2 つになった（観察）。
- 元になったのは、ai-desktop で画面を見ながら案内した 1 回のセッション（2026-10-05、チュートリアル付きの新規開始）。
- 読む人: 画面を見て助言する Claude（`ai-desktop-guide` スキル）と、プレイヤー本人。

## ルールと注意

- 注釈ページから届くのは左クリック（とダブルクリック）だけ。RimWorld はドラッグ（ゾーン、範囲指定、並び替え）と右クリック（「武器を装備する」「優先して建設」など）が多く、これらは RimWorld のウィンドウで操作してもらう（観察）。ブラウザが前面のままだと、キー（スペースで一時停止）もゲームに届かない（観察: 一時停止を頼んだが、ゲームは動いたままだった）。
- 入植者は自分で動くので、ユーザーは Claude を待たずにどんどん先へ進む。待ち受けの間に、チュートリアルを 3 課題ほど進めていたことがある（観察）。報告を受けたら、まず今どの課題かを吹き出しで確かめる。
- 扉や建物の「できた・できていない」を見た目で決めない。Claude は 2 回見誤った（注意）。
  - 青っぽい半透明の扉 → クリックすると「木製ドア(設計)」、木材 0/25 だった（確実）。設計図はまだ建っていない。
  - その後の茶色い扉を「完成」と書いたが、建設中だった（ユーザーの教え）。扉の横の黄色いバーは建設の進み具合（推測）。
  - 確かめ方: その物をクリックしてもらい、左下の名前に「(設計)」が付くか、「残り工数」が出るかを読む（確実: 設計図では「残り工数: 10」「作成に必要なリソース: 木材 0/25」と出た）。
- 紙と瓶の載った茶色い机は「木製研究卓」（確実: クリックして読んだ）。Claude はこれを研究台と気づかず、「研究台を建てる」案内を出した（注意。ユーザーの教え: 「研究台はあります」）。建物の正体は、案内の前にクリックしてもらって確かめる。研究卓の情報に「研究速度係数: 55%（部屋が研究室でない）」「現在の研究」「研究進捗度」が出る（確実）。
- 部屋を壁で囲み、扉が設計図のままだと、中の入植者が出られない（ユーザーの教え: 「部屋から出れないです」）。外にいる入植者を選び、扉を右クリックして優先して建てさせる（推測: この回は、そのあと扉が建った）。
- 赤い × と数字の付いた物資は「禁止」の状態で、入植者が運ばない（確実: チュートリアルの説明文）。
- ベッド（寝床）を選ぶと、下に「解体」「所有」「囚人用ベッドに設定」「医療用ベッドに設定」「複製」のボタンが出る（確実）。
- 「寝床」は家具のメニューの下段、左から 3 番目。材料なしで置ける（確実: ボタン名。材料なしは推測）。
- 倒れた敵は、放っておくと亡くなることがある（観察: 襲撃者 Zensay は意識不明 → 約 10 時間後に「(死亡)」）。
- 死体は墓に埋める。墓を置くと、入植者が掘って死体を運んで埋めた（観察: 墓の情報に「収容: Zensay, 木こり (死亡)」）。墓を選ぶと「解体」「開ける」「複製」のボタンが出る（確実）。
- 「放浪する野蛮人の女性」は、野人が来たときの表示（観察: その人物 Bucky の情報は「メス, 年齢 23, 野蛮人の女性」、ボタンは動物と同じ「狩猟」「手懐ける」だった）。野人は手懐けるとふつうの入植者になる。手懐けるには「動物」7 以上が要る。失敗すると 10%、傷つけると 50% の確率で襲ってくる（出典: <https://rimworldwiki.com/wiki/Events>）。
- 救助は「看護」ができる人だけ（推測: Bryn は看護ができないので、Tail に頼んだ）。
- ゲームの時間は、ユーザーがいないあいだも進む（観察: 待ち受けの間に第一節 6 日 → 8 日まで進んだ）。

## 用語

| 画面の言葉 | 意味 |
|---|---|
| 選択済 ／ 置き去り | キャラクター作成で、連れて行く人 ／ 連れて行かない人（確実） |
| 炎マーク（技能の横） | 情熱。炎 1 つは興味、2 つは大好き（推測: 一般的な知識。ゲーム内の説明は未読） |
| 苦手・欠点 | その人ができない仕事（推測: 一般的な知識） |
| 備蓄ゾーン | 物を置いておく場所（確実: アーキテクトの説明文「入植者が材料を備蓄する場所を作成します」） |
| 農業ゾーン | 作物を育てる場所（確実: 説明文「入植者が,ある種の植物を栽培しようとするためのゾーン」） |
| 禁止 ／ 許可 | 物を入植者に触らせない ／ 触らせる（確実） |
| (設計) | 建物の設計図。まだ建っていない（確実） |
| 工作台速度係数 | 作業台の速さ。カマドは「80%（部屋が調理場でない）」と出た（確実） |
| 宿舎、極度に悪い (-52) | 部屋の評価。カマドのある部屋で、やや貧しい・ひどく醜い・やや広々・とても汚い と出た（確実） |
