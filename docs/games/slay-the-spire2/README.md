## 0. キャラ共通のルールと注意（2 回目のセッションで追加）

- **愚行（呪い）は、商人のカード削除でも削除できない**（プレイヤーの教え）。
- **ツタが付いたカードは、1 ターンに 1 枚しか使えない**（プレイヤーの教え）。手札に複数あっても、1 枚だけ。
- **手札は基本、次のターンに持ち越せない。** 「温存」の助言は無効。そのターンに使い切る前提で組む。
- 復活する敵がいる（第 3 幕）。倒したあとの画面が「HP 満タン」なら、復活の可能性を疑い、撮り直す。
- イベント「人型の穴」など、**効果が分からない選択は、先に調べる**（Firecrawl の `firecrawl_search`。使えなければ WebSearch）。Firecrawl の MCP はユーザー側に登録済み。
- 脆弱が大きいと被ダメージが増える（推測）。ボス前の HP は **50 以上**を目安にする。
- 休憩所を取りこぼさない。マップは上側が見切れるので、**先の分岐をスクロールして確認**するよう頼む。
- 解析やソウルなど、**引くカードを先に使う**。引いたあと、ボタン「引いた」で撮り直して、手順を出し直す。
- 「ターン終了した」が押されても、画面がまだ同じターンのことがある。撮り直して、エネルギーとターン数を確認する。

## 3. 効いたこと（再現できる）

1. **毒は敵のターン開始時に入る。** 敵の残りが毒以下なら、攻撃の前に倒れる。複数の敵がいる戦闘で特に強い。
2. **毒はブロックを無視する。** ブロックの厚い敵（貝、ロボ、砂時計）には毒と絞殺で押す。
3. **絞殺**: 使ったあと、カードを 1 枚使うたびに敵が HP を 2 失う（ブロック無視）。ナイフを 10 枚以上使うターンは、**絞殺を最初に使う**。
4. **ナイフの雨**: ナイフが全体攻撃になる。敵が複数のとき、剣の舞とナイフの雨の組み合わせで 1 ターンで全滅を狙える。
5. **フィニッシャー**: そのターンに使った攻撃の数に比例してダメージ。攻撃カードを先に使い、最後に使う。
6. **アドレナリン（0 コスト）**: エネルギーが増えてカードを引ける。パワーを同じターンに出しやすくなる。
7. **弱体（無力化+）**: 攻撃の多い敵の被ダメージを減らせる。0 コストなので、毎ターン使う価値がある。
8. 状況によって、**ブロックを張らずに攻める**判断が正しいターンもある（敵の意図が攻撃でないとき）。

## 5. 失敗の原因と教訓（最後の危機）

HP が 67 → 34 → 2 と減った。原因は次のとおり。

1. **ブロックのカードが手札にない状態で、攻撃に全振りした。** ターン 5 の助言で「受けるダメージは 21 前後」と見積もったが、実際は約 33 だった。**見積もりが甘かった**（敵の攻撃力の上昇を織り込めていなかった）。
2. **デッキが 36 枚まで膨らんだ。** ナイフ系ばかりが増え、ブロックの札を引く確率が下がった。第 3 層では、カード報酬を取りすぎない方がよかった。
3. **無限の刃を 3 枚目まで取った。** 手札がナイフで溢れる。
4. **最後の敵の攻撃の伸び方に対して、守りの札が足りなかった。**

次に生かすこと:
- 大きな攻撃の前の**ターンの最初に、必要なブロック量を数える**。足りなければ、攻撃より先に、ドロー（アクロバット+、アドレナリン）で守りを探す。
- 守りが不安なときは、バースト+ とブラー+（またはサバイバー）を組み合わせてブロックを 2 倍にする。用意周到で、バースト+ を翌ターンに持ち越せる。
- 商人では、**カード削除を優先**する。ストライクと状態異常・呪いを消す。
- カード報酬は、第 2 層以降は、スキップを積極的に選ぶ。
- 最後の敵の前は、HP を満タンに近づける（休憩で回復）。HP が 30 台で挑まない。

## 6. ai-desktop で助言するときの実務メモ

- **状態アイコン、敵の意図、レリック、見切れた手札の説明文は `move_mouse` で読む。** ゲームの説明文は画面の中に描かれるので、`capture_window` の画像の座標を渡せばよい。読めた内容は、このノートの敵ごとのメモやキャラ別ノートに追記する。
- **アニメーション中は撮り直す。** 毒のエフェクト、手札を配る途中、戦闘開始の文字などで、敵の意図や手札が隠れる。数秒おいて、もう一度 `capture_window` する。
- **ボタンで「ターン終了した」を押されても、ゲームが追いついていないことがある。** 撮り直した画像で、ターン数とエネルギーを確認してから案内する（実際に、ターンの途中で押されたことがあった）。
- `wait_for_message` が `{"message": null}` のときは、黙って呼び直す（5 回続いたら止める）。
- ゲームの相談では、ボタンと入力欄（`message_box=True`）の両方を出すとよい。今回は「中央のネズミは毒で死ぬのでは？」「引いたカード」など、ボタンで表せない発言がチャット経由で届いていた。
- 画像の座標（1568×917 の撮影）の目安:
  - カード報酬（3 枚）: 左 x≈400–600、中央 x≈685–885、右 x≈965–1165、y≈395–670。「スキップ」は (785, 780) 付近。
  - 「ターン終了」ボタン: (1390, 755) 付近。
  - 手札は画面下部 y≈730–915 に扇状に並ぶ。**左端と右端が切れる**ので、読めないカードがあると言う。
  - 商人: カードが上の 2 段、レリックとポーションが右下、カード削除は右下の金貨。
  - 敵は画面右側（x≈900–1500、y≈300–650）。
- 注釈の座標は撮影画像のピクセル。説明（`explanation`）に、使う順番と数字（ブロック量など）を書くと、ユーザーが迷わない。
- 読めないものは推測で埋めず、「効果が読み取れませんでした。カーソルを合わせて確認してください」と伝える。
