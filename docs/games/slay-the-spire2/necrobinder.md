# ネクロバインダー（破滅とオスティ）のナレッジ

元になったセッション: ゲーム v0.107.1（2026.06.18）、日本語表示、ai-desktop で画面を見ながら助言。
全体の注意（共通ルール・実務メモ）は [README.md](README.md)。**確実に分かっていることと、推測を分けて書く。**

## 1. セッションの結果

- フロア 48（第 3 幕の最終ボス戦、ターン 6）で敗北（HP 0/83）。到達階 48、倒したエリート 3、ボス 2、獲得ゴールド 1003。
- 最終ボスは 2 体（左 199・攻撃 12×3 → 16×3 と上がる／右 400・強化とブロック）。左は破滅 97 まで積んだが、HP 146 に届く前にやられた。
- 敗因: ボス前に休憩所を通れず HP 23 前後で挑んだ。足元に脆弱 99 などの状態が付き、守りが足りなかった。

## 2. キャラの仕組み（画面から読めたもの）

| 要素 | 内容 |
|---|---|
| 破滅 | 敵に付く数値。**敵の HP 以下になった（HP ≤ 破滅）敵が倒れる**。ブロック無視。倒れるのは、**敵のターン終了時**が多かった（終末の日だけは使った瞬間に倒れた）。 |
| オスティ | 召喚で HP が増える味方。**攻撃を受け止める役**になる。49 ダメージの攻撃でも、HP 6 の消費で済んだことがあった（推測: オスティが吸収）。 |
| 召喚 N | オスティの HP を +N。解き放つ・つっつき・パチンなどのダメージは、オスティの現在 HP に依存するものがある。 |
| 保留 | 手札に残り、ターン終了で捨てられない（パチンなど）。**手札は基本、持ち越せない**。 |
| エセリアル | 使わないと消える。 |

## 4. 効いた作戦（再現できる）

1. **破滅の積み順**: ① パワー（カウントダウン、影の衣）→ ② 逃げ場なし（既存の破滅が多いほど強い）→ ③ 終末の日。破滅が HP を超えれば倒せる。
2. **複数の敵は終末の日で一掃**: 小さい敵 3 体は、負の波動（全体 +7〜11）→ 終末の日（+29）で 1 ターンで全滅した。順番は、**波動が先**（先に積まないと HP に届かない）。
3. **敵の意図が攻撃でないターンは、ブロックを捨てて破滅を積む**。攻撃が来るターンは、ブロックを先に確保する。
4. **ソウル（0 コスト）と解析で手札を回す**。守りや終末の日が見つかる。ターンの最初に使う。
5. **憂鬱は 0 コストになることがある**。破滅で敵が倒れたあとは、コストを確認する。
6. **完璧な適合のエンチャントを終末の日に付けた**: 山札を一巡したあと、毎回先頭に来た（推測の効き方。効果はシャッフル時に山札の先頭に置く）。
7. 商人は、**カード削除**と**逃げ場なし**を優先して買う。

## 6. 失敗の原因と教訓

1. **HP が減ったまま、ボス戦に入った。** 休憩所を取りこぼした。第 3 幕では、マップを見て、ボスの手前の休憩所を必ず通る。
2. **守りのカードが少ない**（防御 4 枚、墓守・憂鬱・負の波動のみ）。破滅を積むほど、守りの札を引く確率が下がる。守りは **ブロック付きの破滅カード（負の波動）** で兼ねたい。
3. **ツタ付きのカードは、1 ターンに 1 枚しか使えない**（プレイヤーの教え）。ボスの効果と推測。**ツタ付きの手札を、守りと攻撃の両方に取らない**。
4. **愚行（呪い）は削除できない**（プレイヤーの教え）。商人のカード削除の候補にしない。
5. 敵の攻撃が連続で上がるボス戦は、**HP が 50 以上ないと勝てない**。HP 低下時は、休憩所、洋ナシのレリックなどで最大 HP を伸ばす。
6. 見積もりが甘かった。受けるダメージを数えるときは、**脆弱の倍率と、攻撃回数の増加（12×3 → 16×3）** を織り込む。

## 7. 確認できていないこと

- ボディガードや蘇生で「召喚 20」にした場合の、オスティの受け止め方。
- 負の波動のブロックが、脆弱・脱力でどう減るか。
- 破滅のあと、倒れるタイミング（敵のターン終了時 / 手番開始時）の厳密な規則。
- 解析を使うと、ほかのツタ付きが使えなくなる、という推測。
- 足元の各種アイコン（砂時計、はさみ、3 種類の「99」、赤いコイルなど）の意味。
